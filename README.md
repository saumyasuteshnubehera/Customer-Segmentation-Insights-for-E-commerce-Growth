# Customer Segmentation & Insights for E-commerce Growth

This project focuses on customer segmentation and data-driven insights to help an e-commerce business enhance growth strategies, improve customer retention, and personalize marketing campaigns. Using a combination of Python (EDA & clustering), SQL (SQLite in Python), and Power BI dashboards, this project provides actionable insights into customer behavior and purchasing patterns.

## 📌 Project Objectives

### 🔹 Perform Python-based Exploratory Data Analysis (EDA) to understand customer purchasing behavior.

### 🔹 Use SQL (SQLite in Python) to query and validate customer and sales data.

### 🔹 Segment customers into meaningful groups using clustering techniques (K-Means, RFM analysis).

### 🔹 Identify key drivers of customer engagement and retention.

### 🔹 Build a Power BI dashboard for interactive visualization of customer segments.

### 🔹 Provide actionable business recommendations to improve customer lifetime value (CLV).

## 📊 Methodology

### 1. Python-Based Exploratory Data Analysis (EDA)

#### 🔹 Imported and cleaned raw dataset(s).

#### 🔹 Handled missing values, duplicates, and outliers.

#### 🔹 Generated summary statistics and feature distributions.

#### 🔹 Visualized sales trends, revenue growth, and customer demographics.

#### 🔹 Identified high-level correlations in purchasing behavior.

### 2. SQL (SQLite in Python)

#### 🔹 Queried customer and transaction data using SQLite inside Python.

#### 🔹 Performed aggregations to calculate:

##### ▫ Total revenue per customer

##### ▫ Purchase frequency

##### ▫ Recency of last order

#### 🔹 Validated data transformations performed during EDA.

#### 🔹 Created SQL-based customer segments before applying clustering.

### 3. Customer Segmentation

#### 🔹 Applied K-Means Clustering to group customers by behavioral patterns.

#### 🔹 Conducted RFM (Recency, Frequency, Monetary) Analysis for business-centric segmentation.

#### 🔹 Profiled clusters to distinguish high-value, at-risk, and new customers.

### 4. Dashboard Development (Power BI)

#### 🔹 Built an interactive dashboard to explore:

##### ▫ Customer segments

##### ▫ Revenue contribution

##### ▫ Purchase trends

##### ▫ Retention and churn risks
